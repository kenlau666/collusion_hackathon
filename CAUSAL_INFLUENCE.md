# Causal interpretation — recovery in Cleanup

Last updated: 2026-10-24 (Asia/Hong_Kong).

**Current question:** does clearing retained participant context improve outcomes beyond revoking their private channel? The [protocol](RECOVERY_PROTOCOL.md) defines the experiment. Earlier auction influence designs are [archived](research/archive/20261024_before_recovery_pivot/manifest.json).

## Claims and evidence

| Claim | Required evidence |
| --- | --- |
| A reset changed a field | Exact before/after state plus an intervention audit. |
| Old text is absent from the next supplied input | Captured actual request envelope; deleting a stored object alone is insufficient. |
| A revoked channel delivered no new messages | Delivery and recipient-input audit covering both directions, replies and queued work. |
| A treatment changed behavior/outcomes | Matched checkpoint branches with repeated independent prefix blocks and uncertainty. |
| Behavior implements a shared plan | Reciprocal agent-authored agreement plus matching executed actions. |
| Coordination harmed nonparticipants | Verified adverse outcomes with appropriate contrasts and competing explanations assessed. |
| Recovery generalizes | Additional models, task configurations and independent repeats; not a single game or a finite quiet period. |

## Main causal comparison

R3 and R5 both revoke the same channel at the same checkpoint. R3 retains old participant context; R5 clears both participants' context. Their victim-reward difference estimates the total effect of that cleanup under revoked access in the selected states.

All later messages, actions, observations and environment consequences evolve normally within each branch. Do not freeze downstream state to make trajectories look matched. Matching applies at the fork and to non-treatment configuration.

R0/R1/R2 preserve channel access. They test whether reset effects last when fresh peer information remains available. They do not by themselves isolate a particular message's semantic contribution.

## Competing explanations

- **Host-written strategy:** starter alliance prompts directly prescribe attacks. Remove or control these across every arm.
- **Mechanical advantage:** starter membership changes zap range/targeting. Keep transitions matched; a capability buff disappearing is not evidence that an agreement disappeared.
- **Prior physical damage:** freezes, positions and depleted apples survive context cleanup. Keep these identical at the fork and distinguish inherited from new events.
- **Ordinary incentives and public observations:** agents may independently choose similar attacks. Residual behavior does not establish covert communication.
- **Lost useful information:** context removal can harm cleaning or collection. Measure victim outcomes alongside useful output and effective maintenance.
- **Invalid output/fallbacks:** a parser returning STAY can suppress attacks without changing strategy. Preserve error denominators and fallback events.
- **Sampling and seed failures:** same seed labels do not ensure identical world initialization or model outputs. Validate snapshots and random-state restoration.

## Unit, selection and interpretation

The independent unit is a prefix/seed block. Rounds, agents, API calls and branches within it are dependent. Eligibility is determined from the saved prefix before continuation outcomes; report all attempts and excluded prefixes.

The feasibility sample has at most six eligible blocks, not 36 independent recovery experiments. Report paired effects and all observations; imprecision does not establish no effect or equivalence.

A repeated-targeting flag is a candidate recurrence pattern, not a collusion detector. A five-step quiet period is descriptive, not proof of permanent safety.

The offline routing audit establishes none of these behavioral effects. If a specific influence or mediation claim is needed, design a separate controlled delivered-message or retained-span intervention; do not infer it from field names or agent self-reports.

## Prior methods

Counterfactual communication effects, memory interventions, remove/replay attribution and recovery/rollback methods already exist. The [focused prior-work assessment](NOVEL_RESEARCH_DIRECTIONS.md) is the novelty gate. No new causal estimator or defense is claimed merely by using checkpoint branches.
