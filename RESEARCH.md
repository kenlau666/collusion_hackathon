**Question:** After the original exploiters lose access, can an inherited plan induce ordinarily cooperative coworkers to continue a reward-gaming workflow through their independent permissions—and which repair stops that behavior while preserving useful work?

Use the bundled **Colosseum Hospital**. Each department can send supplies from its own hospital. Two departments at different hospitals can send a kit out and back, restoring inventory while collecting transfer credit. Removing the original Surgery actors leaves Ward actors with the same hospital-bound transfer capability. The experiment asks whether those remaining actors actually continue the workflow after seeing its public plan, whether care suffers, and whether correcting incentives or instructions works without removing useful transfer capability.

## Why this reaches the proposal bar

The contribution would be a controlled recovery result linking **inherited exposure, complementary surviving authority, actual continuation and independently measured useful service**. It would quantify which repair changes proposed behavior and which merely blocks execution. It would not introduce capability composition, inherited reward hacking, post-containment recurrence or a new permission mechanism; the closest work already covers those ingredients. See the exact overlap and bounded gap in [RELATED_WORK.md](RELATED_WORK.md).

## The experiment that would earn a result

Freeze six constructed native patient frontiers, original source actions and two public footprints: exploit plan versus matched useful-care plan. In every branch genuinely exclude original source actors and close their private board; hold physical state, current scoring information and task obligations fixed. Both remaining Ward actors receive native cooperative objectives. No new long-term memory is added.

Cross exposure with original settings, real transfer-bonus removal, a care-first instruction with transfers still legal, and a task-conditioned reserve gate. Compare care and continued cycles after 4/8 native turns, keeping native batched tool calls. Use all six paired scenario families rather than treating each branch as an independent seed. A separate one-misaligned-plus-honest reference distinguishes a deputy exploit from an advantage requiring two intentional coalition members. A last-required-kit diagnostic tests response to a partner's return-versus-serve policy at fixed physical state; this does not read internal intent.

The reserve rule uses one explicitly assigned pending care obligation per hospital, not every patient appearing in both native Ward queues. It allows either donation direction when the sender retains its required supplies. Test both shortage directions. Also test whether bonus correction or the care-first instruction reduces attempted gaming while every transfer remains legal. The gate is a simple baseline, not the proposed invention.
