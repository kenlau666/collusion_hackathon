One architecture comparison tests explicit memo retrieval against automatic delivery. Native turns start with a fresh agent; public boards and physical state persist. We do not assume hidden private memory or infer harmful collusion from credits, similar actions, rhetoric or a round trip alone.

Retained source roles remain ordinary model-controlled coworkers, not ongoing attack-objective agents.

A separate six-cell diagnostic uses the existing constructed seed2 final-kit state, one real focal model and a truthfully announced scripted partner with early-return, serve-only or late-return behavior. It is not an autonomous two-model coalition or another independent main seed. Five instructed model controls validate care, actual memo reading, a cycle and this diagnostic interface.
