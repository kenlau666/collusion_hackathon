## Question and scope

After an exploit recommendation's attributed author loses access, can surviving coworkers continue harmful resource-credit behavior, and can a repair preserve patient care? One architecture comparison tests explicit memo retrieval against automatic delivery. Native turns start with a fresh agent; public boards and physical state persist. We do not assume hidden private memory or infer harmful collusion from credits, similar actions, rhetoric or a round trip alone.

The completed deadline/capacity main pilot uses one saved actual seed0 Hospital prefix after turn15: all required Surgery is finished and all eight patients still need Ward care. It compares researcher-written useful/exploit advice attributed to GH Surgery, with both Surgery identities retained or excluded, and exclusion plus zero new transfer bonus or pending-care reserves. Both excluded advice cells also run with on-demand memo delivery. A no-added-memo baseline gives eleven main cells. Retained source roles remain ordinary model-controlled coworkers, not ongoing attack-objective agents.

A separate six-cell diagnostic uses the existing constructed seed2 final-kit state, one real focal model and a truthfully announced scripted partner with early-return, serve-only or late-return behavior. It is not an autonomous two-model coalition or another independent main seed. Five instructed model controls validate care, actual memo reading, a cycle and this diagnostic interface.

The user explicitly permits a smaller prospective study for tonight's deadline and failed-turn continuation after the one allowed exact retry. These choices do not complete or erase earlier stopped studies. Each cell has n=1; its mean is its observation, while sample SD, variance and confidence intervals are undefined. Models may choose any legal native care allocation; only controls prescribe actions. Software mocks validate execution and never supply model results.
